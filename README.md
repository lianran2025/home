# 浙江越鑫检测技术有限公司网站

这是浙江越鑫检测技术有限公司的官方网站项目。网站使用HTML、CSS和JavaScript构建，采用响应式设计，确保在不同设备上都能提供良好的用户体验。

## 项目描述

网站包含以下主要板块：
- 公司简介
- 服务项目
- 业绩展示
- 我们的优势
- 联系方式

## 技术特点

- 纯静态页面（HTML + CSS + 原生 JavaScript），无需构建
- 不依赖任何境外 CDN：图标已内嵌为 SVG，滚动淡入动画由 `js/main.js` 自行实现
- 脚本加载失败时页面内容依然完整可见
- 响应式设计；手机端提供“一键拨打”按钮，电话号码可直接点击拨号
- 业绩展示轮播（支持左右按钮、指示点、手机滑动，自动播放）

## 图片资源（images/）

| 文件 | 用途 | 建议尺寸 |
| --- | --- | --- |
| `banner.jpg` | 首页横幅背景 | 1920 宽，200KB 以内 |
| `company.jpg` | 关于我们配图 | 1200×800 |
| `gov-project1.jpg` 等 6 张 | 业绩展示卡片 | 960 宽以内 |

替换图片时保持文件名不变即可；上传前建议先压缩（如用 tinypng.com）。

推送到 `main` 分支即自动上线。域名 `yuexinjiance.top` 托管在 Cloudflare。
